Privacy Policy

Last updated: October 5, 2026

What the app accesses

Family Organizer requests read-only access to Google Calendar (https://www.googleapis.com/auth/calendar.readonly) for the account that authorizes it. It reads the list of calendars and their events so they can be displayed on a tablet in our home.

How data is used and stored

  • Calendar data is used only to display events on the household dashboard.
  • The app runs on a private server on our home network. OAuth tokens are stored on that server only.
  • Event data is cached briefly in memory and is not written to a database.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

Family Organizer's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from your Google Account third-party connections page.
